# CreateYourNotes Scoop Bucket

A custom [Scoop](https://scoop.sh) bucket for **CreateYourNotes** — a local-first
notes app for Windows 10 and later. Your notes stay on your PC: no account,
no sync, no tracking.

## Install

```powershell
scoop bucket add createyournotes https://github.com/vishallinux542/scoop-bucket
scoop install createyournotes
```

## Update

```powershell
scoop update createyournotes
```

## Apps in this bucket

| App name  | Description                                   | Homepage                                              |
| --------- | --------------------------------------------- | ----------------------------------------------------- |
| `createyournotes` | CreateYourNotes for Windows (WPF, .NET 8) | https://github.com/Vishalkirthik-TV/createyournotes |

## Releases

Release assets are published on the
[createyournotes releases page](https://github.com/Vishalkirthik-TV/createyournotes/releases).
Each release version corresponds to the `version` field in
[`bucket/createyournotes.json`](bucket/createyournotes.json).
